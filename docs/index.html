HamChannel

An OFDM soundcard data modem for VHF/UHF FM ham radios. Send text messages and files between two stations through the audio jacks or bluetooth to the radio — with LDPC forward error correction and a reliable selective-repeat ARQ layer.

What It Does

HamChannel turns a laptop and an FM radio into a digital data link. Wire the laptop's headphone output to the radio's mic input and the radio's speaker output back to the laptop's mic input, and two stations can exchange text and files over the air. The modem uses multi-carrier OFDM, systematic LDPC codes with a CRC on every block, and a half-duplex ARQ protocol that resends only the chunks that were lost — so file transfers complete reliably even on a marginal link. Every transmitted frame carries your callsign for station identification. Bluetooth handy-talkies in the Benshi family can be used cable-free.

Get on the Air

  1. Wire the laptop's headphone out to the radio's mic input (through a 10:1 attenuator or isolation transformer), and the radio's speaker/data out back to the laptop's mic in.
  2. Enable VOX on the radio, or use a supported Bluetooth handy-talkie for cable-free keying.
  3. Open Settings, enter your callsign, pick the audio devices, channel width and modulation, and set the TX level.
  4. Set volumes so the RX meter reaches mid-scale without clipping; start narrow and step up only if the link stays solid.
  5. Use the Messages and Files tabs to exchange data with the other station.
